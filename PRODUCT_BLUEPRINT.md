# CurioQuest — Complete Product Blueprint

**Version:** 1.0  
**Purpose:** Product definition and development source-of-truth  
**Primary audience:** Founder, product designer, curriculum designer, software engineer, AI engineer  
**Initial learner ages:** Pre-K through Grade 2  
**Initial private beta:** Two learners — one Pre-K, one Grade 1

---

# 1. Product Vision

CurioQuest is an adaptive whole-child learning universe for young children that uses adventures, stories, puzzles, construction, creativity, conversation, sibling collaboration, and real-world missions to systematically develop:

- literacy
- mathematics
- science
- logic
- reasoning
- executive function
- communication
- social-emotional skills
- creativity
- engineering thinking
- life skills
- physical/fine-motor skills
- general world knowledge

The product should feel like an adventure game to the child, a learning coach to the parent, and a structured learner-intelligence platform underneath.

The goal is not to maximize screen time.

The goal is to help children become capable, curious, independent learners who can:

- read
- reason
- solve problems
- explain ideas
- build
- create
- collaborate
- apply learning in the real world

---

# 2. Core Product Promise

## To the child

> Explore a world, solve mysteries, build things, unlock powers, and go on adventures.

## To the parent

> Know what your child understands, what they are ready to learn next, and exactly how to help.

## To the CurioQuest learning engine

> Continuously estimate what the learner knows, identify misconceptions, select appropriate next experiences, and revisit knowledge before it is forgotten.

# 3. Product Philosophy

CurioQuest should be built around the following principles.

## 3.1 Mission-first, not menu-first

Children should not primarily see a grid of school subjects.

Instead of:

- Math
- Reading
- Science
- Logic

the child enters missions such as:

- Save the Magical Garden
- Repair the Robot City
- Rescue the Lost Dinosaurs
- Build the Moon Base
- Find the Missing Rainbow

The academic structure exists underneath the story.

## 3.2 Active thinking over passive tapping

Every activity should ask:

- Is the child thinking?
- Is the child making a decision?
- Is the child explaining?
- Is the child creating?
- Is the child applying knowledge?

## 3.3 Learn → Apply → Explain → Create

A core CurioQuest instructional cycle should be:

1. Discover
2. Try
3. Practice
4. Apply
5. Explain
6. Create
7. Review later

## 3.4 Digital learning should trigger real-world learning

CurioQuest should frequently move learning away from the screen.

Examples:

- find three objects beginning with /B/
- grow a seed
- measure a table
- build a bridge from blocks
- sort household objects
- observe shadows
- count grocery items
- find geometric shapes outside

## 3.5 Healthy engagement

CurioQuest should deliberately avoid:

- infinite feeds
- gambling-like mechanics
- loot boxes
- aggressive streak anxiety
- advertisements in the child experience
- manipulative notifications
- guilt-based retention

The system should sometimes tell the child:

> Your brain worked hard today. Your next adventure is in the real world.

# 11. Daily Quest

Every learner receives a personalized daily adventure.

The default experience should have one obvious primary action:

> START TODAY'S QUEST

A typical session:

- 3 min — brain warm-up
- 5–6 min — literacy
- 5–6 min — math
- 3–5 min — logic/science
- 5 min — creation/building
- optional real-world mission

Target structured screen time:

- approximately 20–30 minutes

Parent controls should override this.

# 20. Mastery Model

A child should not master a skill from one activity type.

Evidence should include:

- accuracy
- independence
- hint use
- response time
- transfer
- delayed retention
- explanation
- number of contexts
- number of activity formats

Conceptual initial weighting:

```text
Mastery =
35% Accuracy
20% Independent Performance
15% Retention
15% Transfer
10% Explanation
5% Response Confidence
```

These weights must later be validated empirically.

---

# 21. Mastery Confidence

Mastery and certainty should be stored separately.

Example:

```text
Skill: Addition within 10

Estimated mastery: 87%
Confidence: HIGH

Evidence:
42 attempts
6 activity types
4 sessions
3 contexts
```

Compare:

```text
Skill: Telling time

Estimated mastery: 91%
Confidence: LOW

Evidence:
4 attempts
1 activity type
```

The second skill should not yet be considered secure.

---

# 22. Spaced Review

A mastered skill should return naturally.

Illustrative review schedule:

- Day 1
- Day 3
- Day 7
- Day 14
- Day 30
- later mixed review

The child should not experience this as repetitive review.

It should appear inside new stories and missions.

---

# 23. Misconception Detection

CurioQuest should try to identify why an answer is wrong.

Examples:

## Reading

- b / d confusion
- p / q confusion
- short e / short i
- sh / ch
- omission of final sounds

## Mathematics

- double counting
- weak one-to-one correspondence
- addition used instead of subtraction
- teen-number reversal
- equality misunderstood
- place-value confusion

The system should respond with targeted instructional support.

---

# 24. Adaptive Difficulty

If performance is strong:

```text
Level 1 → Level 2 → Level 3
```

If performance weakens:

```text
Level 3
 ↓
Visual support
 ↓
Manipulatives
 ↓
Worked example
 ↓
Prerequisite check
```

Nova should say:

> Let's try another way.

Never:

> You failed.

---

# 25. Product Difficulty Zone

Most adaptive activities should aim for meaningful challenge.

Initial target:

- roughly 60–80% independent success

Too easy:

- boredom

Too difficult:

- frustration

The exact band can later be tuned with learner data.

# 26. Explain-It Feature

A signature CurioQuest feature should ask the learner to explain.

Examples:

- How did you know?

- What clue helped you?

Responses may be:

- voice
- touch selection
- drawing
- sentence
- ordered steps

This helps distinguish real understanding from guessing.

- You're a genius!
- Perfect!
- Amazing every time!

# 47. Hint Ladder

Example:

Problem:

8 + 5

Hint 1:

> Can we make ten?

Hint 2:

Show 8 dots and 5 dots.

Hint 3:

Ask how many remain.

The goal is strategy, not answer delivery.

# 59. Frustration Signals

CurioQuest can observe behavioral patterns without diagnosing mental state.

Signals:

- rapid repeated incorrect answers
- repeated hints
- unusually long inactivity
- multiple quits
- repeated back-and-forth selections

Response:

> This one is tough. Want to try a different puzzle?

No penalty.

# 84. Recommendation Engine V1

Start deterministic, not machine-learning-heavy.


# 111. Product Definition

CurioQuest is an adaptive whole-child learning universe for young children that uses adventures, stories, puzzles, construction, creativity, conversation, sibling collaboration, and real-world missions to systematically develop academic knowledge, reasoning, executive function, communication, and practical skills.

Underneath the child experience is a learner model that continuously estimates:

- what the child knows
- what they are ready to learn next
- what they are forgetting
- where misconceptions exist
- which learning experience is most appropriate

The child experiences a world.

The parent experiences a learning coach.

The platform underneath is an educational intelligence system.
