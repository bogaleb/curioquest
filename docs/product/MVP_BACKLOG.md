## Next implementation order

1. Complete family ownership and server-authorized parent controls before widening access. Define an explicit migration of existing single-family records; never assign them to an arbitrary first visitor.
2. Expand curriculum in reviewed strands, including missing placement domains. Each skill needs content, feedback, prerequisites, and evidence variety.
3. Improve quest composition and recovery, including offline support with conflict-safe synchronization. A real-world mission is not offline application support.
4. Test the child/parent/sibling experience with actual families and fix observed usability and learning-content problems before public release.

Do not label the app complete or mastery estimates validated until these criteria are met.
