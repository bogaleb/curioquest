# Wave 13 — Parent Dashboard, Controls, Reports, and Trust

## Goal

Bring the parent experience to the same commercial quality level as the child experience.

## Parent Dashboard

Show useful, understandable information:

- child profiles
- learning time
- activities completed
- subject progress
- skills mastered
- skills developing
- recent activity
- achievements
- weekly trends
- recommended focus
- reading progression
- math progression

Do not display arbitrary or fake percentages.

## Reports

Support:

- Today
- This Week
- This Month

Use understandable language.

## Parent Controls

Allow control of appropriate settings such as:

- session duration
- preferred subjects
- learning goals
- interests
- sound/music
- optional difficulty settings
- movement/off-screen activities
- profile settings

## Parent Security

Protect:

- account
- billing/subscription placeholders if present
- settings
- exports
- child profile management

Use parent-only gating where appropriate.

## Artwork/Activity History

Where available, provide:

- recent creations
- recent stories
- achievements
- activity timeline

## Recommendations

Provide useful recommendations tied to actual activity/mastery data.

Examples:

- continue practicing short-vowel decoding
- review addition within 20
- try the next habitat activity

Avoid diagnostic/medical language.

## Completion Criteria

- polished parent dashboard
- data is real
- parent controls persist
- parent-only areas are protected
- production build passes
