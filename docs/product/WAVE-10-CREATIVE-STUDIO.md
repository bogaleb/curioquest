# Wave 10 — Drawing and Creative Studio

## Goal

Transform the basic drawing experience into a polished children's Creative Studio.

## Core Tools

Where appropriate include:

- pencil
- marker
- brush
- crayon
- eraser
- paint bucket
- shapes
- lines
- stamps
- stickers
- background/template selection
- brush size
- undo
- redo
- clear
- save

## Creative Modes

Support:

- free drawing
- coloring
- tracing
- finish the picture
- symmetry
- draw an animal
- illustrate a story
- create a scene
- design something
- invention challenge
- pattern creation

## Age Adaptation

Younger children:

- fewer visible tools
- bigger controls
- simplified palette
- guided prompts

Older children:

- more tools
- richer templates
- design challenges
- story illustration
- open-ended creation

## Fullscreen

Creative Studio should support immersive/fullscreen mode and adapt to orientation changes.

## Persistence

Where practical:

- save artwork to child profile
- create child artwork gallery
- expose parent-controlled export/share options

Do not expose public sharing.

## Completion Criteria

- responsive canvas
- usable on iPad touch
- undo/redo and save
- age-adaptive tool complexity
- production build passes
