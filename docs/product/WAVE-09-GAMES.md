# Wave 09 — Learning Games

## Goal

Turn Games into a polished learning-game library built on reusable engines.

## Principle

A game should not merely be a quiz with decorative graphics.

The gameplay mechanic itself should require thinking or skill practice.

## Reusable Game Engines

Consider engines such as:

- Memory Match
- Word Builder
- Phonics Pop
- Number Race
- Sorting Challenge
- Pattern Explorer
- Shape Builder
- Maze
- Puzzle Assembly
- Sequence Challenge
- Letter Hunt
- Treasure Hunt
- Visual Memory
- Listening Challenge
- Science Sort
- Story Builder
- Logic Challenge

## Configuration

Each engine should support relevant configuration by:

- age
- grade
- subject
- skill
- difficulty
- content set

Avoid creating separate codebases for every game.

## Required Controls

Provide where appropriate:

- instructions
- replay instructions
- pause
- resume
- restart
- exit
- fullscreen
- sound control
- progress
- accessibility support

## Age Adaptation

Younger games:

- simpler goals
- larger targets
- shorter rounds
- stronger audio cues

Older games:

- multi-step goals
- deeper strategy
- more complex scoring/challenges

## Educational Integrity

Every game should identify:

- target skill
- learning objective
- age range
- difficulty

## Completion Criteria

- reusable game framework
- meaningful game variety
- responsive/fullscreen support
- progress saving
- production build passes
