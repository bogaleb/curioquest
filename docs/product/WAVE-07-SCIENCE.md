# Wave 07 — Science and Exploration

## Goal

Make Science feel like investigation and discovery rather than a quiz section.

## Core Learning Cycle

Prefer:

observe
→ predict
→ test
→ compare
→ classify
→ manipulate
→ discover
→ explain

## Topic Areas

Use age-appropriate versions of:

- animals
- habitats
- plants
- life cycles
- weather
- seasons
- human body
- senses
- Earth
- rocks
- oceans
- ecosystems
- space
- planets
- forces
- motion
- magnets
- light
- sound
- matter
- simple machines

## Younger Learners

Emphasize:

- observation
- matching
- sorting
- cause/effect
- sensory concepts
- simple predictions

## Older Learners

Add:

- comparisons
- evidence
- multi-step reasoning
- simple data
- explanation
- scientific vocabulary

## Interactive Formats

Build reusable formats such as:

- classify animals
- build a habitat
- order a life cycle
- weather observation
- drag-and-test magnet activity
- force/motion prediction
- states-of-matter sorting
- solar-system exploration
- body-system interaction
- simple virtual experiment

## Real-World Connection

Where safe and parent-appropriate, include optional off-screen exploration:

- observe the sky
- compare leaves
- find shadows
- sort household objects
- notice weather

## Completion Criteria

- science includes interaction beyond quizzes
- age-specific depth
- real skill/progress linkage
- production build passes
