# Wave 03 — Child Home, Navigation, and Today's Adventure

## Goal

Turn the child home into a personalized learning hub that answers: "What should I do now?"

## Home Experience

Prioritize:

- Today's Adventure
- Continue Learning
- Recommended Next
- recent achievement
- Explore
- favorite activities where useful

Do not overwhelm younger children with too many choices.

## Age Adaptation

### Ages 3–5

Use:

- larger visual choices
- minimal text
- stronger audio guidance
- fewer simultaneous options

### Ages 5–7

Use:

- clearer subject paths
- early progress indicators
- moderate text

### Ages 7–9

Use:

- more independent navigation
- clearer goals
- deeper challenge options
- more mature visual treatment

## Today's Adventure

Create a data-driven daily sequence informed by:

- age
- grade
- unfinished activity
- recent activity
- subject balance
- future mastery signals
- interests

Initial structure may include:

Reading
→ Math
→ Brain Break
→ Science
→ Logic
→ Creative Activity
→ Story

Do not require every child to complete the same sequence every day.

## Navigation

Make it:

- obvious
- age-appropriate
- touch-friendly
- consistent

Avoid overly complex menu systems for young children.

## Continue Learning

Persist enough state to return the child to unfinished work.

## Completion Criteria

- home feels personalized
- profile age visibly changes content presentation
- Today's Adventure works from real data/configuration, not hard-coded demo arrays
- navigation is clear on iPad and desktop
- production build passes
