# Wave 05 — Reading and Language Arts

## Goal

Transform Reading into a structured, age-adaptive literacy program rather than a collection of simple questions.

## Learning Progression

Support:

phonological awareness
→ phonemic awareness
→ alphabet knowledge
→ phonics
→ decoding
→ word recognition
→ vocabulary
→ fluency
→ sentence comprehension
→ passage comprehension
→ inference
→ informational reading
→ writing connection

## Ages 3–4

Focus on:

- environmental sounds
- listening
- vocabulary
- rhyme exposure
- picture naming
- letter familiarity
- story listening

Use audio and images heavily.

## Pre-K

Focus on:

- rhyme
- syllables
- beginning sounds
- letter recognition
- letter sounds
- vocabulary
- oral comprehension
- print awareness

## Kindergarten

Focus on:

- phonemic awareness
- systematic phonics
- blending
- segmenting
- CVC words
- decodable words
- simple sentences
- early comprehension

## Grade 1

Focus on:

- phonics progression
- decoding
- fluency
- spelling
- vocabulary
- sentence structure
- short passages
- main idea
- details
- sequencing
- inference foundations

## Grade 2

Focus on:

- longer passages
- vocabulary in context
- grammar
- summarization
- inference
- informational text
- spelling/writing connection

## Grade 3

Focus on:

- deeper comprehension
- informational text
- vocabulary
- grammar
- paragraph structure
- evidence from text
- summarization
- inference

## Interaction Types

Build variety:

- tap the sound
- choose the picture
- rhyme matching
- segment sounds
- blend sounds
- build words
- word-picture matching
- sentence ordering
- read and answer
- vocabulary exploration
- story sequencing
- spelling
- read-to-me
- read-yourself

Avoid making every activity multiple choice.

## Feedback

Feedback should teach.

Examples:

- "Listen to the first sound."
- "Try blending these sounds slowly."
- "Look back at the sentence for a clue."

Use age-appropriate language.

## Content

Add enough structured content to feel substantial, but do not generate repetitive filler.

Prioritize depth, progression, and variety.

## Completion Criteria

- clear age-based reading paths
- multiple reusable reading activity types
- progress connected to reading skills
- content stored in scalable structures
- production build passes
