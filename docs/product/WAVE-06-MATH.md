# Wave 06 — Mathematics

## Goal

Transform Math into an age-adaptive, visual, reasoning-oriented experience.

## Learning Approach

Use concrete → representational → abstract progression where appropriate.

Use visual models before relying on symbols alone.

## Ages 3–4

Focus on:

- counting small quantities
- matching quantity to number
- shapes
- size comparison
- simple patterns
- sorting

## Pre-K

Focus on:

- number recognition
- counting
- one-to-one correspondence
- more/less
- shapes
- patterns
- ordering
- simple composition

## Kindergarten

Focus on:

- counting
- number relationships
- composing/decomposing numbers
- addition/subtraction foundations
- ten-frame concepts
- comparison
- measurement concepts
- geometry

## Grade 1

Focus on:

- addition/subtraction
- place value
- number lines
- word problems
- time
- money introduction
- measurement
- geometry
- patterns

## Grade 2

Focus on:

- multi-digit addition/subtraction
- place value
- measurement
- time
- money
- multiplication foundations
- fraction foundations
- multi-step reasoning

## Grade 3

Focus on:

- multiplication
- division
- fractions
- multi-step word problems
- geometry
- measurement
- number relationships

## Interaction Types

Support:

- counters
- ten frames
- drag groups
- number lines
- manipulatives
- arrays
- matching
- sorting
- balance/comparison
- shape construction
- word-problem visualization
- quick fluency practice
- reasoning challenges

Avoid plain text question + four-button design as the default.

## Feedback

Use hints that reveal strategy without immediately revealing the answer.

Examples:

- "Try making a group of ten first."
- "Move the counters to see the total."
- "What does the number line show?"

## Completion Criteria

- age-specific progression
- reusable math interaction engines
- visual models
- skill-based progress
- production build passes
