# Wave 08 — Logic, Memory, Executive Function, and Brain Training

## Goal

Build a serious reasoning area that develops thinking skills through age-appropriate challenges.

## Skill Areas

Include:

- pattern recognition
- sequencing
- classification
- analogies
- mazes
- spatial reasoning
- visual discrimination
- auditory discrimination
- working memory
- visual memory
- planning
- inhibitory control
- cognitive flexibility
- cause and effect
- deduction
- coding-style sequencing

## Ages 3–5

Use:

- picture patterns
- matching
- simple memory
- simple sequences
- sorting
- find-the-difference
- simple maze

## Ages 5–7

Add:

- more complex patterns
- sequence prediction
- simple analogies
- route planning
- working-memory tasks
- visual logic

## Ages 7–9

Add:

- multi-step logic
- coding-style sequencing
- deductive puzzles
- more complex spatial tasks
- strategy challenges

## Game-Like Presentation

These activities may feel playful, but avoid excessive stimulation.

Track skill performance separately where practical.

## Completion Criteria

- multiple reusable logic activity formats
- clear age-based difficulty
- meaningful progress tracking
- production build passes
